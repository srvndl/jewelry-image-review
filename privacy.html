Your images stay in your review tab.

Jewels Retouch · Updated 25 October 2026.

Browser review tool

The review tool processes selected source and edited images in your browser tab using local object URLs. It does not upload image pixels, filenames, checklist selections, or notes. There are no analytics, remote scripts, remote fonts, API calls, automatic saves, cookies, or application storage. Reset or close the tab to discard the review; browser memory reclamation is browser-managed.

When you choose Download review JSON, your browser creates a local file containing filenames, image types, byte sizes, dimensions, a UTC timestamp, manual review choices, and notes. It contains no image pixels. Downloaded files and browser download history remain until you remove them. Filenames and notes can be sensitive: review them before sharing an export.

GitHub Pages hosting

This resource site is hosted on GitHub Pages. Loading its HTML, scripts, styles, images, or downloads sends normal HTTP requests to the hosting service. GitHub may process IP addresses and request information in hosting and security logs under its own policies. Local processing of your chosen images does not mean that visiting a hosted page leaves no server logs.

Read GitHub’s privacy statement.

Extension

The unpacked Chrome extension uses local tab memory, requests no host permissions, and includes no telemetry, content scripts, remote code, or network connections for image review. Website links make requests only when you activate them. Read the packaged extension policy.

Outbound links

Links to Jewels Retouch and other websites are optional. Their own services and policies apply when you follow a link. This resource site does not submit your selected images to Jewels Retouch.
