# Answer: approve the piece first

A useful retouched photo represents the specific item. Review identity before judging the background or shine.

---

# Write a destination brief

Record model code, destination, crop, background, and details that must remain visible. Keep the original file unchanged.

---

# Check construction

Count visible stones. Compare outline, prongs, links, closures, and engraving. Stop approval if a critical feature changes.

---

# Check presentation

Review edge quality, reflections, shadow, background, and crop at full size and at intended display size.

---

# Route the result

Approve; request a defined correction; send for manual finishing; or reshoot when source evidence is missing. Save the reason and version.
