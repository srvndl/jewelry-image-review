Keep jewelry image review one click away.

The free desktop Chrome extension opens this manual comparison tool in a separate local extension tab. Compare images, record eight checks, and export review JSON. No account or remote image processing.

Download extension ZIP · version 1.0.0Full instructions

Install locally in desktop Chrome

  1. Download and extract the ZIP. Keep the extracted folder on your device.
  2. Open chrome://extensions in desktop Chrome and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Click the extension’s toolbar action to open a fresh review.

This is an unpacked distribution. Chrome Web Store publication or approval is not claimed. Chrome extensions are for desktop Chrome; you can use the browser-based review tool without installing anything.

What the tool does

Your judgment drives the checklist. It does not automatically detect image changes, certify product accuracy, measure dimensions, or calibrate color. Each image is limited to 25 MB, 60 megapixels, and 16,000 pixels per side. Review one pair at a time.
